# SAHAR v8 — ТЗ «Premium Sweets Store» (2026-10-20)

Вторая редакция ТЗ (поверх SPEC.md). Витрина уже live на GitHub Pages + Cloudflare Worker + KV.

## Дизайн
- Белый фон #FFFFFF основной, дополнительный #FAF9F7, текст #252321, вторичный #8A8580, активные элементы тёмно-шоколадный #4B2B20, разделители #ECE9E5, акцент карамель #D8B99C. Минимум теней, никакого неона/тяжёлых градиентов.
- Логотип текстовый SAHAR, тонкий элегантный шрифт, допустим небольшой символ цветка/конфеты над названием, в шапке занимает мало места, подзаголовок «КОНФЕТЫ · СЛАДОСТИ · ПОДАРКИ».
- Нижняя навигация: 4 вкладки (Магазин, Избранное, Сообщения, Профиль), белая компактная панель, тонкая линия-разделитель, контурные иконки с подписями, активная тёмная, неактивные серые, не перекрывает контент, состояние сохраняется при переходах.

## Главная (Магазин)
- Шапка: логотип, звонок уведомлений с индикатором непрочитанных, поиск «Поиск сладостей…», страна, корзина с бейджем.
- Небольшой рекламный баннер с реальным фото, CTA «Перейти в каталог».
- Категории компактной сеткой (иконки), реально фильтруют.
- Секции: Популярные товары, Новинки, Подарки, Акции, Рекомендуемые.
- Карточки: фото, название, вес/кол-во, цена, кнопка избранного, кнопка добавления в корзину; «Осталось N» при малом остатке; товар без остатка нельзя добавить.

## Каталог
- Фильтры: по категориям, сортировка по цене/популярности, фильтр «В наличии», фильтр «Со скидкой», сброс фильтров, понятное пустое состояние.
- Данные из базы (API), не статика.

## Страница товара
- Большое фото, название, цена, вес, наличие, описание, состав и аллергены (если есть), страна происхождения (если известна), количество, «Добавить в корзину», избранное, похожие товары, краткое подтверждение после добавления, состояние корзины обновляется без перезагрузки.

## Корзина
- Открывается по действию, сохраняется между сессиями. Изменение кол-ва, удаление, пересчёт, промежуточная сумма, доставка, итог. Пустое состояние: иллюстрация, «Ваша корзина пуста», кнопка «Перейти в каталог».

## Оформление заказа — 4 шага
1. Контактные данные: имя, телефон (междунар. формат), страна, город, адрес, комментарий.
2. Доставка: курьер / почта, тарифы по стране, бесплатная от порога.
3. Оплата: только реально работающие в стране способы; при переводе — реквизиты с копированием. Никаких фейковых онлайн-платежей.
4. Подтверждение: состав, суммы, итог, согласие с офертой, кнопка «Подтвердить заказ». Уникальный номер после создания. Сервер перепроверяет цены/остатки/доставку; итог не принимается с клиента.

## СНГ
- Страны: UZ/KZ/KG/TJ/RU/BY/AM/AZ (+MD/GE). Валюты UZS/KZT/KGS/TJS/RUB/BYN/AMD/AZN, курсы задаются в настройках (не фиктивная конвертация), форматирование по валюте, оплата и доставка только по выбранной стране.
- Языки: русский основной, узбекский, английский (архитектура под каз/кыр/тадж).

## Избранное
- Добавить/удалить/перейти/добавить в корзину; сохранение между визитами; аккуратное пустое состояние.

## Сообщения
- Две вкладки: Чаты (реальная поддержка: написать, отправить фото, получить ответ) и Уведомления (статусы заказов, треки). Индикатор непрочитанных в звонке шапки. Никаких фиктивных переписок.

## Профиль
- Имя, телефон/ID, Мои заказы (номер, дата, состав, суммы, статус, история статусов, только свои), Адреса доставки (добавить/выбрать/удалить, подстановка в чекаут), Избранное, Настройки (страна/язык/тема), Помощь/FAQ, Оферта, Конфиденциальность. Авторизация через проверенную подпись Telegram (HMAC на сервере, ID с клиента не доверять).

## Админ-панель (CRM)
- Товары: создать/изменить/скрыть/удалить (soft-delete)/восстановить/дублировать, фото, остатки, цены,desc RU/EN/UZ.
- Заказы: список, поиск, смена статусов, трек, CSV.
- Категории, баннеры, промокоды, клиенты, чат (ответ текстом и фото, непрочитанные), рассылки, настройки (курсы, оплата по странам, анимации, магазин open/close).
- Защита: проверка владельца на сервере на КАЖДОМ запросе (initData HMAC + OWNER_IDS).

## Технические
- Telegram Mini App: safe-area, тёмная/светлая тема, без горизонтального скролла, быстрая загрузка, ленивые изображения, состояние корзины/избранного восстанавливается, повторные запросы не дублируют заказы (idempotency), загрузка/пустые состояния/ошибки везде.
